Автотесты программы LIVARO (для разработки, бухгалтеру не нужны).

Один раз в этой папке:
    npm init -y
    npm install jsdom@24.1.0

Запуск одного теста:
    node flow_test.js

Тест исправен, если в конце печатается «errors: []» и нет строки «FAIL».
Тесты читают программу из C:/Users/user/Desktop/LIVARO/ — при переносе папки поправьте путь в начале файлов.
